1 Already have the app?

Move Whyfull to its permanent location first (on Mac, the Applications folder). Then open it and choose Whyfull → Install command-line tool… The app shows where it put the launcher (on Mac and Linux, ~/.local/bin/whyfull); add that folder to your PATH if it isn’t there already. 

whyfull --json

2 Just want the CLI?

Download an archive, extract it, and keep the launcher beside its runtime folder. Run ./whyfull (Windows: whyfull.cmd), or add the extracted directory to PATH.

Already using Node.js?

npm works too.

A small install for scripts, CI, and a quick first report. Requires Node.js 22.18 or later. Prefix the same commands with npx, or install them globally.

Run once, using the latest npm release:

npx whyfull@latest

Or install or update the command:

npm install -g whyfull@latest

Copy a command and run it on the computer you want to inspect.

A little help getting started.

Opening an unsigned Mac preview

Unsigned previews haven’t been signed with an Apple Developer ID or notarized by Apple. macOS may prevent them from opening. If you downloaded a preview from this page or our GitHub Releases and trust that copy:

  1. Open the DMG, move Whyfull to Applications, and try launching it.
  2. Open System Settings → Privacy & Security.
  3. Find the message about Whyfull, choose Open Anyway, and confirm opening it.

This creates an exception for that app. Read Apple’s instructions ↗. If macOS reports damage or malware, download a fresh copy or report the problem.

How do updates work?

Stable desktop releases check for signed updates on launch and from Whyfull → Check for updates…. You choose when to install and restart.

  • CLI installed from the app: follows the app, so it uses the new engine after each desktop update. Running a report never checks for updates.
  • Standalone archive: replace the extracted directory with a newer release. Archives don’t update themselves.
  • npm: run npm install -g whyfull@latest, or use npx whyfull@latest.
  • Linux: AppImage follows desktop updates; DEB installations update by installing a newer package.

With more than one installation, the first whyfull on your PATH runs. Check with command -v whyfull (Windows: where whyfull).

How do I uninstall Whyfull?
  1. Mac: quit Whyfull and drag it from Applications to the Trash. Windows: use Settings → Apps.
  2. If you installed the command-line tool from the app, delete its launcher: rm ~/.local/bin/whyfull (Windows: %LOCALAPPDATA%\Whyfull\bin\whyfull.cmd).
  3. Optional: remove saved settings, Keep/Exclude rules, and scan caches, shared by the app and CLI, with rm -rf ~/.config/whyfull (or $XDG_CONFIG_HOME/whyfull if you set it). Folder scans with --directory also keep a .whyfull cache inside that folder.

npm installations: npm uninstall -g whyfull. Standalone archives: delete the extracted directory.

Yes. Run whyfull --json and give the results to your agent. Reports may include private file paths; you choose what to share. Install the Whyfull skill or copy the agent prompt →
