For your terminal & your agent

One command.
Two ways to install.

Both run the same report. Neither needs a separate Node.js installation.

Use the CLI with your coding agent ↗

1 Already have the app?

Install it in its permanent location first. On Mac, move it to Applications. Open Whyfull and choose Whyfull → Install command-line tool…

The app shows the launcher location. Add that directory to PATH if needed. The command follows the app when it updates. 

whyfull --json

2 Just want the CLI?

Download an archive, extract it, and keep the launcher beside its runtime folder. Run ./whyfull (Windows: whyfull.cmd), or add the extracted directory to PATH.

Mac · Apple Silicon TAR.GZMac · Intel TAR.GZWindows · x64 ZIPLinux · x64 TAR.GZ

Update by replacing the extracted directory with a newer release. Standalone CLI archives don’t update themselves.

Already using Node.js?

npm works too.

A small install for scripts, CI, and a quick first report. Requires Node.js 18.15 or later.

Run once, using the latest npm release:

npx whyfull@latest --json

Or install or update the command:

npm install -g whyfull@latest

npm manages this installation separately from the desktop app. If you install both, PATH determines which command runs.

Copy a command and run it on the computer you want to inspect.

A little help getting started.

Opening an unsigned Mac preview

Unsigned previews haven’t been signed with an Apple Developer ID or notarized by Apple. macOS may prevent them from opening. If you downloaded a preview from this page or our GitHub Releases and trust that copy:

  1. Open the DMG, move Whyfull to Applications, and try launching it.
  2. Open System Settings → Privacy & Security.
  3. Find the message about Whyfull, choose Open Anyway, and confirm opening it.

This creates an exception for that app. Read Apple’s instructions ↗. If macOS reports damage or malware, download a fresh copy or report the problem.

How do updates work?

Stable desktop releases check for signed updates on launch and from Whyfull → Check for updates…. You choose when to install and restart. Preview builds use manual downloads and don’t follow the stable update channel.

The app’s installed CLI uses the updated engine after a desktop update. Running a terminal report does not check for updates. Standalone archives update by directory replacement; npm installations update through npm.

Can my coding agent use the report?

Yes. Run whyfull --json and give the results to your agent. Reports may include private file paths; you choose what to share. Install the Whyfull skill or copy the agent prompt ↗
