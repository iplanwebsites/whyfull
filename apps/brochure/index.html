Reports read metadata. Viewer cleanup starts in demo mode every session. Keep folders you need, exclude folders from future scans, and review your options before changing anything.

One command.
A little clarity.

Open your terminal on the computer you want to inspect. With Node.js and npm installed, run the command below. No global install needed; npm downloads the package on first use. 

npx whyfull@latest --view

The viewer opens in your browser and runs on your computer. Its assets are bundled and work offline after download. Use a current Node.js release; Node.js 22.18+ is recommended for this workflow.

Prefer the terminal? Run npx whyfull@latest for the known-tool report, or add --json for your agent. Stop the viewer with Ctrl + C.

Read the command reference ↗
Pick your starting point
# Report known tool locations and caches
npx whyfull@latest

# Explore your disk visually
npx whyfull@latest --view

# Focus on one folder (macOS / Linux)
npx whyfull@latest --view --root ~/Downloads

# Give your agent a structured report
npx whyfull@latest --json

# Reopen a saved disk snapshot
npx whyfull@latest --view --snapshot disk.json

Your files stay on your computer.

A local view.

The authenticated viewer server binds to 127.0.0.1. Scans read file metadata, and Whyfull does not upload your disk inventory. An agent you use has its own data handling settings.

Context before cleanup.

Large does not always mean disposable. Shared caches and model stores may overlap. Allocated and logical sizes can differ, and measured space is not guaranteed reclaimable space.

Cleanup is a separate decision.

Real Trash moves require macOS 14+, an explicit launch flag, enabling Trash in the viewer, and individual confirmation. Saved snapshots support demo cleanup only.
