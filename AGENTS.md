# UI work

Read [docs/ui-principles.md](docs/ui-principles.md) before changing any user-facing UI.
Apply it to the viewer, desktop shell, public site, dialogs, empty states, and feedback.
Keep labels and actions concise; remove redundant explanation instead of adding it.
Persistent sections and panels belong in URL state, with working direct links,
reloads, and browser Back/Forward. Keep transient confirmations and drafts local.
